# 경주김씨 · 공개 프로젝트 안내

이 저장소는 경주김씨 프로젝트의 공개 안내와 아카이브를 관리합니다.

[전체 프로젝트 인덱스](https://softm.github.io/projects/)

## 현재 상태

공개 안내 홈 소스 `index.html`을 생성했습니다. 현재 원문 아카이브는 0개이며 사진·영상·음성 등 원본 자료와 비공개 배포 주소는 아직 등록되지 않았습니다.

웹 사이트의 GitHub Pages 배포가 확인되기 전에는 이 저장소 안내를 공개 프로젝트 진입점으로 사용합니다. 준비되지 않은 인증 링크나 자료를 임의로 표시하지 않습니다.

자료가 등록되면 공개 가능한 설명은 이 저장소에, 비공개 원문과 첨부는 GitHub Private에 보관하고 인증된 Vercel 경로로 연결합니다.

[전역 아카이브 배포 규칙](https://github.com/softm/softm.github.io/blob/main/projects/README.md)
